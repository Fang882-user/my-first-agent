# My First AI Agent
## 项目简介:
本项目是我在大一学习python过程中，结合了相关知识，独立完成的第一个工程化练手项目。项目实现了一个标准的python包结构，并内置了日志记录功能
## 核心功能
-**模块化设计**:使用'agent_utils'包管理核心代码,结构清晰。
-**日志记录**:基于'logging'模块，自动将运行信息写入‘agent.log’,支持中文。
-**异常处理**:读取配置文件时，使用try-except机制处理‘文件不存在的情况’。

## 技术栈
-**语言**:Python 3.13
-**核心库**:'logging','os'
-**编程范式**:OOP,异常处理机制
